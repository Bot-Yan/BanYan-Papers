# TreeNext 架构、性能与功能审查

审查日期 2026-11-15。基线为 `f57e6d5` 和审查时的本地工作区。范围包括 TreeNext 静态站、Node 服务、测试、部署流程，以及相邻 Console 和 Backend 的对接代码。记录包含前两轮发现和本轮补查项。生产清单、真实流量、线上 Nginx 配置和外部离线发布工具需要另外验证。

「复现」表示用本地受控输入观察到异常。「代码」表示有明确实现依据。「待验证」表示影响取决于数据、运行环境或使用情况。「缺口」表示可按产品需求决定是否补齐的能力。每条均含定位和可落地的改法。

## 目录和存储架构

1. **线上目录和离线重扫都能写清单〔代码、待验证〕**。网页上传和整理变更依赖离线发布程序重放事件。工作区找到了事件生产端和文档，实际重扫程序需要联调。明确一个权威写入入口。离线扫描先生成差异，再交由目录服务合并。用实际工具验证上传、改名、下架以及新建、移动、解散和压平目录经过重扫后仍生效。 [重扫约定](../README.md#L34)
2. **变更成功与日志持久化脱节〔代码〕**。先替换清单再追加 `uplog.json`。追加失败只写控制台，读取日志失败可能重建为空，历史固定裁到 1,000 条。若离线消费者尚未确认，历史可能丢失。对事件分配持久序号，记录消费进度，按确认进度归档，且能在重启后补偿未完成的提交。 [目录写入](../scripts/tree2-files-server.mjs#L1416) · [日志](../scripts/tree2-files-server.mjs#L1752)
3. **单进程串行队列只能防同一进程内的写入交错〔代码〕**。上传涉及对象、口令额度、清单和日志，原子替换只覆盖各个 JSON 文件。优先明确失败后的恢复协议和幂等提交。如果业务要求目录、口令额度和事件在一次事务内提交，可把这些元数据迁入嵌入式 SQLite，文件字节继续用现有对象库，JSON 继续作为导出格式。目录写、上传和外部重扫需一道验证。 [队列](../scripts/tree2-files-server.mjs#L142) · [上传提交](../scripts/tree2-files-server.mjs#L1616)
4. **目录操作各自维护查找、命名和提交逻辑〔代码〕**。整理会按 Unicode 规范化和忽略大小写检查同级冲突，改名按同类型及精确名称检查，上传会按路径补目录。整合到一个目录模块，统一路径解析、兼容旧条目、命名策略、统计和缓存失效，保持现有 API 兼容。 [整理](../scripts/tree2-arrange.mjs#L42) · [改名](../scripts/tree2-files-server.mjs#L1303) · [挂接](../scripts/tree2-files-server.mjs#L1708)
5. **批次名称兼作权限标识〔代码〕**。批次改名会让原来按「届别 + 批次名」授权的口令失去这个批次。引入持久批次 ID，迁移时保留口令、有效期和使用次数。补一条「改名后原链接仍能向正确批次上传」的测试。 [改名批次](../scripts/tree2-files-server.mjs#L1360) · [口令范围](../scripts/tree2-files-server.mjs#L1503)
6. **对象引用和物理回收耦合在下架请求里〔代码〕**。下架在写队列内读取多份清单及映射，将原文拼成字符串检查 SHA。上传先落对象，后续挂接失败也可能留下无引用对象。统一引用检查，加入可核对的候选清单，再按备份和恢复约定回收。先验证同一对象跨届、跨分享和音频映射引用的场景。 [下架](../scripts/tree2-files-server.mjs#L1244) · [上传落对象](../scripts/tree2-files-server.mjs#L1638)
7. **统计存在多个写入来源和多次遍历〔代码〕**。同一棵树分别统计文件数、目录数和字节，挂接后还会把 `uniqueFiles` 置空。届列表是独立文件，验收时应核对其数量与各届清单的一致性。统一一次遍历产出派生统计，并明确哪个组件负责更新届列表。 [清单统计](../scripts/tree2-files-server.mjs#L388) · [挂接统计](../scripts/tree2-files-server.mjs#L1740)
8. **服务入口混合 HTTP、目录写入、对象 I/O、分享 HTML、ZIP 和音频〔代码〕**。以现有 `tree2-arrange.mjs` 为例按职责抽出可独立测试的目录、对象上传、分享与打包逻辑。路由继续集中注册，先抽重复逻辑和副作用，避免为每个接口单独建一层。 [服务入口](../scripts/tree2-files-server.mjs#L407)

## 浏览、导航与缓存

9. **并发切届会混合不同届的数据〔复现〕**。模拟 2026 清单在 2027 之后返回，最终显示 2027，清单实际是 2026，入库状态来自 2027。并行读取目标届两份数据，只提交最新导航的一组结果。切换失败保留前一个完整状态。 [切届](../public/tree2/js/app.js#L433)
10. **拼音搜索两栏不一致〔复现〕**。测试批次拼音 `fzyj`，左侧命中 1 项、右侧 0 项。右侧漏用批次拼音，并重复拼接文件拼音。统一路径拼音和类型匹配，左右共用命中数据。 [左侧搜索](../public/tree2/js/app.js#L517) · [右侧搜索](../public/tree2/js/app.js#L791)
11. **刷新、历史导航和预览各有一套恢复步骤〔代码〕**。首次加载会主动清掉目录、筛选和文件参数，历史导航会在切届前尝试从当前清单定位文件。集中解析 URL、加载清单、恢复视图和处理已删除路径。补深链接刷新、跨届前进后退和关闭预览的用例。 [URL 读取](../public/tree2/js/app.js#L196) · [历史导航](../public/tree2/js/app.js#L1331)
12. **普通浏览也会重建整棵可见树〔代码〕**。点击后重建 DOM、绑定行监听器和递归计算目录数量。搜索又对已命中的子树重复匹配。按届建立路径与计数索引，保留折叠分支的懒渲染，优先只更新选中状态与展开分支。 [目录渲染](../public/tree2/js/app.js#L503) · [子节点渲染](../public/tree2/js/app.js#L638)
13. **长目录与搜索结果一次渲染全部命中项〔代码、待验证〕**。目录切换重复拍平和排序，搜索直接追加全部行。先测低端手机上的输入延迟和列表渲染耗时，再决定分批渲染或分页。 [搜索结果](../public/tree2/js/app.js#L805) · [目录列表](../public/tree2/js/app.js#L931)
14. **长期停留的标签页可能一直使用旧清单〔代码〕**。成功请求按届缓存在内存中，切回同一届会直接复用。按 API 地址与届别区分缓存，在切届或页面重新聚焦时按需用 ETag 验证，离线时保留上次成功快照。 [清单缓存](../public/tree2/js/api.js#L116)
15. **入库查询失败显示成「未入库」〔代码〕**。超时或网络错会被转换为空键集合。区分未知、可在线和确实未入库，给失败状态一个重试入口。该接口还会每次扫描全量对象库，可复用现有短期缓存并在上传、删除和外部同步后失效。 [浏览器入库状态](../public/tree2/js/api.js#L140) · [服务端入库状态](../scripts/tree2-files-server.mjs#L431)
16. **清单读路径重复读文件、计算哈希和构建索引〔代码〕**。原始清单响应、对象键集合和分享元数据有独立读写路径。按同一个清单版本派生原始响应、ETag、文件键和元数据索引。外部导入也需要触发失效。 [文件键缓存](../scripts/tree2-files-server.mjs#L341) · [清单响应](../scripts/tree2-files-server.mjs#L415) · [分享索引](../scripts/tree2-files-server.mjs#L631)
17. **收藏夹跨届状态取当前届〔代码〕**。收藏遍历依次请求各届，渲染时在线状态仍看全局当前届，预览也从当前届取地址。数据加载可并行，行携带所属届及其入库状态。也应明确同一个哈希在多个目录出现时是收藏内容还是收藏条目。 [收藏夹](../public/tree2/js/app.js#L831) · [文件行](../public/tree2/js/app.js#L993) · [在线判断](../public/tree2/js/app.js#L181)
18. **本地收藏数据损坏可能阻止应用启动〔代码〕**。模块初始化直接读取并解析 `localStorage`，写入已有保护。读取时验证是数组，对损坏值或不可用存储回退为空集合。 [收藏存储](../public/tree2/js/app.js#L1139)
19. **请求超时只覆盖响应头〔代码〕**。`request` 在读取响应体前清除计时器，接收已中止信号以及移除监听的逻辑也应归一。把读响应体纳入超时范围，并区分主动取消、超时、HTTP 错误和无效 JSON。 [请求封装](../public/tree2/js/api.js#L72)
20. **PWA 缓存生命周期需要收窄〔代码、待验证〕**。激活时会清当前 origin 下所有其他缓存名。静态缓存会保存失败响应，旧版本 URL 也会积累。清理范围限于 TreeNext 自己的缓存，只存成功且允许缓存的响应，验证离线访问、更新及子路径挂载。 [Service Worker](../public/tree2/sw.js#L3)

## 文件预览、分享和下载

21. **关闭预览后下载仍可能继续，80 MiB 限制生效太晚〔代码〕**。打开新文件或关闭时取消旧请求，清单大小可作前置判断，读取中再限制实际字节。图片路径仍经浏览器 `fetch` 转 Blob，应验证大图是否可直接用原生图片加载。 [预览加载](../public/tree2/js/app.js#L1073) · [流读取](../public/tree2/js/api.js#L162) · [图片预览](../public/tree2/js/preview.js#L104)
22. **非 PDF 预览缺少统一的销毁和过期保护〔代码〕**。图片和错误回退创建 Blob URL，Word、表格、文本的异步步骤也可能在切换后写入容器。统一预览会话，取消网络请求、释放对象 URL，异步渲染完成时只提交当前会话。 [预览分发](../public/tree2/js/preview.js#L104) · [Word](../public/tree2/js/preview.js#L500) · [表格](../public/tree2/js/preview.js#L560)
23. **站内和分享落地页维护两套预览规则〔代码〕**。服务端模板单独做了格式判断和渲染。梳理两边支持范围、失败回退和脚本加载差异，能共用的放进现有预览模块，分享落地页保留直接下载。 [站内预览](../public/tree2/js/preview.js#L104) · [分享落地页](../scripts/tree2-files-server.mjs#L654)
24. **文件夹改名或移动后旧分享 URL 会失效〔代码〕**。`/d/` 按当前路径逐级找目录。可给可分享目录稳定 ID，或在改名、移动时记录旧路径跳转。明确下架后的失效行为并覆盖历史链接测试。 [生成分享](../public/tree2/js/app.js#L1233) · [查找目录](../scripts/tree2-files-server.mjs#L1015)
25. **内容对象和目录条目共用分享身份〔代码、待验证〕**。新文件链接定位内容键，相同内容在多个届别或名称下只有一个分享元数据条目。核对「下架某个条目后旧链接应如何表现」和「同一字节多个名称用哪个展示」。需要保留分享上下文时给链接独立记录。 [分享元数据](../scripts/tree2-files-server.mjs#L631) · [内容键分享](../scripts/tree2-files-server.mjs#L829)
26. **文件夹打包遇到一个未入库的条目就整体失败〔代码〕**。按钮未事先说明缺件或大小限制。可先报告缺件和预计体积，按产品需求允许只打包已入库文件，并列出跳过项。 [打包按钮](../public/tree2/js/app.js#L961) · [打包限制](../scripts/tree2-files-server.mjs#L1040)
27. **ZIP 的冷缓存读两遍，断连时流缺少明确清理〔代码〕**。先算 CRC 再传文件，等待 `drain` 的逻辑未处理连接关闭。先让断连中止读流和等待，再测量实际目录，决定缓存或在入库时保存 CRC。同时校验 ZIP 格式的条目数量、路径长度边界和中途中断的反馈。 [CRC](../scripts/tree2-files-server.mjs#L985) · [ZIP 流](../scripts/tree2-files-server.mjs#L1083)
28. **空文件读取缺少独立分支〔代码〕**。上传可用单个零字节分片，下载路径仍按 `end = size - 1` 创建读流。给空文件明确的 GET、HEAD、Range 行为和往返测试。 [上传分片数](../public/tree2/customer.html#L252) · [对象读取](../scripts/tree2-files-server.mjs#L522)
29. **格式支持与可用性提示有落差〔缺口〕**。PPT 和旧版 Word 使用下载回退，已入库标记却统一写「可预览」。优先把「已入库」「可预览」「仅下载」显示准确，是否为 PPT 生成预览取决于真实使用量。 [文件行](../public/tree2/js/app.js#L993) · [格式分发](../public/tree2/js/preview.js#L104)
30. **预览与分享弹层需要键盘和焦点验收〔待验证〕**。文件行和目录树同时有按钮与整行点击，关闭、打开、焦点恢复以及手机触控存在多条入口。用键盘和触屏走一次完整流程，覆盖弹层关闭后回到原文件行。 [预览 DOM](../public/tree2/index.html#L59) · [触控处理](../public/tree2/js/app.js#L567) · [分享弹层](../public/tree2/js/app.js#L1188)

## 上传和管理

31. **管理员和顾客页各维护一套上传协议〔代码〕**。已共用哈希与会话 ID，秒传探测、分片和提交仍重复。把传输流程收进 `upload-file.js`，由页面注入认证头、目标和进度回调，ZIP 展开放在顾客页面。 [共享上传](../public/tree2/js/upload-file.js) · [管理员](../public/tree2/admin.html#L440) · [顾客](../public/tree2/customer.html#L218)
32. **上传缺少同会话重试、取消和跨刷新恢复〔缺口〕**。一次网络失败就结束当前文件，重新选择文件会生成新 ID。先补分片级超时、重试与取消，再根据实际传输时长决定是否持久化会话。提交响应丢失或重复提交时，应避免重复扣顾客额度。 [顾客分片](../public/tree2/customer.html#L206) · [服务端提交](../scripts/tree2-files-server.mjs#L1620)
33. **顾客批次上传缺少可靠的结果汇总〔代码〕**。每个文件失败后队列继续，最终统一显示「全部完成」。显示成功、失败、跳过与待重试数量，并支持仅重试失败项。 [顾客队列](../public/tree2/customer.html#L327)
34. **ZIP 展开依赖 JSZip 内部字段〔代码〕**。总解压大小从 `_data.uncompressedSize` 读取，进入单文件任务后才累计实际字节。把源格式校验集中起来，统一累计条目数和实际展开大小，明确失败的文件与原因。升级 JSZip 时回归空包、较深目录、中文名称和已有包装目录规则。 [ZIP 展开](../public/tree2/customer.html#L264)
35. **管理入口重叠〔代码〕**。Console 和独立管理页均有部分目录管理、口令及统计功能。按实际使用梳理职责，Console 负责带账号权限和审计的日常管理，独立页面可收敛成上传入口或保留必要的独立运维路径。确认既有管理入口后再收敛。 [独立管理页](../public/tree2/admin.html#L74) · [生产代理说明](../../backend/src/tree2-api.mjs#L5) · [Console 资料库面板](../../console/src/components/Tree2Panel.astro#L27)
36. **批量整理与下架恢复〔缺口〕**。现在目录整理支持预览和确认，下架有可能删除无其他引用的对象。可评估批量预览、下架后恢复窗口和操作记录入口，验收范围包括同一内容多处引用以及离线重扫后的恢复行为。 [整理](../scripts/tree2-files-server.mjs#L1388) · [下架行为](../README.md#L25)

## 运行、部署和测试

37. **下载统计会受请求形态和落盘时机影响〔代码〕**。文件存在即计数，HEAD 和多段下载可能让数字偏高。落盘进行期间的新增计数可能被清掉 dirty 标记。定义是计下载请求还是计成功下载，使用单写入队列或版本标记，退出时按需要刷新统计。 [下载计数](../scripts/tree2-files-server.mjs#L499) · [统计落盘](../scripts/tree2-files-server.mjs#L1149)
38. **部分文件系统错误被当成空清单或未入库〔代码〕**。例如届列表读取错误会回空列表，对象遍历失败会返回空集合。区分确实缺失、磁盘权限、数据损坏和临时故障。健康信息体现目录与对象可读性，用户界面显示可重试的失败。 [届列表](../scripts/tree2-files-server.mjs#L409) · [对象遍历](../scripts/tree2-files-server.mjs#L359) · [健康检查](../scripts/tree2-files-server.mjs#L1855)
